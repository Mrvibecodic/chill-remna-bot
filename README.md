Телеграм-бот «магазин + админка» для панели **Remnawave**. Пользователь выбирает тариф, оплачивает и за пару минут получает ключ. Вся настройка — прямо в Telegram: на сервере вы вписываете два значения и запускаете одну команду.

Один бинарь на Go, запуск в Docker (amd64 и ARM64). База данных — SQLite или PostgreSQL (бот поднимает Postgres сам). Конфигурация хранится в БД в зашифрованном виде, поэтому переживает перезапуск.

> 📖 **Документация: https://remna.shop/** — установка, настройка, платёжки, обновление, FAQ и скриншоты.

## Коротко о возможностях

- **Тарифы и витрина**: сколько угодно тарифов, у каждого свои имя, значок, описание, сроки и цены, трафик и лимит устройств; доступность (всем / новым / действующим / по списку / по ссылке), экспорт и импорт файлом. Смена тарифа не сжигает остаток.
- **Оплаты**: P2P, Telegram Stars, ЮKassa (с автопродлением), CryptoBot, Platega, Heleket, Tribute — каждый включается отдельно. Платежи идемпотентны, вебхуки проверяются, фоновый реконсилятор добивает оплату, если вебхук не дошёл.
- **Кошелёк, промокоды, рефералка**: баланс в рублях, промокоды на деньги или дни, бонус пригласившему и приглашённому плюс процент с его платежей.
- **Триал, продление, напоминания**, автопривязка к существующим учёткам панели, сброс устройств одной кнопкой.
- **Mini App и веб-кабинет**: то же самое приложением в Telegram и отдельным сайтом; вход по Telegram или e-mail, экран «Подключить» с приложениями под все платформы.
- **Админка целиком в чате**: продажи, маркетинг, интерфейс (баннеры, эмодзи, контакты, документы сервиса), пользователи (поиск, блокировки, режимы доступа, торрент-блокер), система (обновление `/update`, вебхуки, мини-апп, кабинет).
- **Безопасность**: автоблок скам-регистраций, экранирование имён, работа только со своими учётками в панели, шифрование конфига, режимы публичности бота.

Подробный разбор — [«Что умеет бот»](https://remna.shop/start/features/).

## Установка за 4 шага

**1. Возьмите `docker-compose.yml`:**

```bash
mkdir -p /opt/remnachillbot && cd /opt/remnachillbot
curl -fsSL -o docker-compose.yml \
  https://raw.githubusercontent.com/Mrvibecodic/chill-remna-bot/main/docker-compose.yml
```

**2. Впишите два значения** (`nano docker-compose.yml`):

```yaml
      BOT_TOKEN: "123456789:AAEabc..."     # токен от @BotFather
      ADMIN_TELEGRAM_ID: "000000000"        # ваш Telegram ID (число)
```

**3. Запустите:**

```bash
docker compose pull
docker compose up -d
```

**4. Напишите боту `/start`** — откроется мастер настройки: язык, база данных, подключение к панели.

Что нужно на сервере, права API-токена панели, разбор каждого шага и мастера — [«Установка»](https://remna.shop/start/install/) и [«Что нужно перед стартом»](https://remna.shop/start/requirements/).

## Образы и каналы

| Канал | Ветка | Образ |
|---|---|---|
| Stable | `main` | `ghcr.io/mrvibecodic/chill-remna-bot:latest` |
| Dev (превью) | `dev` | `ghcr.io/mrvibecodic/chill-remna-bot:dev` |
| Релиз | тег `vX.Y.Z` | `…:v1.2.3`, `…:v1.2`, `…:v1` |

В `docker-compose.yml` по умолчанию стоит `:v1` — приходят все релизы `1.x.y`. Канал переключается прямо в боте: **Система → Обновление**. Подробнее — [«Каналы релизов»](https://remna.shop/ops/channels/).

## Обновление и бэкап

Обновление — командой `/update` в боте (или `docker compose pull && docker compose up -d`). Бэкапить нужно том `bot-data`: `bot.db` (если SQLite) и `secret.key` — без ключа настройки не расшифровать. Подробности — [«Обновление и бэкап»](https://remna.shop/ops/update/).

## Документация: как править

Сайт документации живёт в этом же репозитории, в папке `site/` (Astro + Starlight). Страницы — обычный markdown в `site/src/content/docs/**`, меню — в `site/astro.config.mjs`. После пуша в `main` GitHub Actions собирает сайт и публикует его на remna.shop.

Локально:

```bash
cd site
npm ci
npm run dev     # http://localhost:4321
```
