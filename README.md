Телеграм-бот «магазин + админка» для панели **Remnawave**. Пользователь выбирает тариф, оплачивает и за пару минут получает ключ. Вся настройка — в Telegram: на сервере вы вписываете два значения и запускаете одну команду.

Запуск в Docker (amd64 и ARM64), база — SQLite или PostgreSQL (Postgres бот поднимает сам). Настройки хранятся в базе в зашифрованном виде.

> 📖 **Документация: https://remna.shop/** — установка, настройка, платёжки, обновление, FAQ и скриншоты.

## Коротко о возможностях

- **Тарифы**: сколько угодно, у каждого свои сроки и цены, трафик и лимит устройств; доступность (всем / новым / действующим / по списку / по ссылке), экспорт и импорт файлом. При смене тарифа остаток не сгорает.
- **Оплаты**: P2P, Telegram Stars, ЮKassa (с автопродлением), CryptoBot, Platega, Heleket, Tribute — каждый включается отдельно. Если уведомление об оплате потерялось, бот перепроверит её сам.
- **Кошелёк, промокоды, рефералка**: баланс в рублях, промокоды на деньги, дни или трафик, бонус пригласившему и приглашённому плюс процент с оплат друга.
- **Триал и продление**: покупка во время триала по тумблеру, возврат неиспользованного триала, напоминания, автопривязка к существующим учёткам панели, список устройств и их сброс одной кнопкой.
- **Mini App и веб-кабинет**: то же самое приложением в Telegram и сайтом; вход через Telegram или по e-mail, экран «Подключить» с приложениями под все платформы. Два дизайна — классический и новый минималистичный со светлой и тёмной темой, названием, цветом и логотипом сервиса (**Интерфейс → 🎨 Дизайн мини-аппа и кабинета**). С настроенной почтой — подтверждение адреса, смена и восстановление пароля, привязка Telegram к аккаунту по e-mail.
- **Админка в чате**: продажи, маркетинг, интерфейс, пользователи (поиск, блокировки, режимы доступа, торрент-блокер), система (подключение к панели, обновление, вебхуки, мини-апп, кабинет, почта, переезд с remnashop).
- **Безопасность**: автоблок скам-регистраций, бот трогает в панели только свои учётки, режимы доступа в бота (публично / по приглашениям / белый список).

Подробнее — [«Что умеет бот»](https://remna.shop/start/features/).

## Установка за 4 шага

**1. Возьмите `docker-compose.yml`:**

```bash
mkdir -p /opt/remnachillbot && cd /opt/remnachillbot
curl -fsSL -o docker-compose.yml \
  https://raw.githubusercontent.com/Mrvibecodic/chill-remna-bot/main/docker-compose.yml
```

**2. Впишите два значения** (`nano docker-compose.yml`):

```yaml
      BOT_TOKEN: "123456789:AAEabc..."     # токен от @BotFather
      ADMIN_TELEGRAM_ID: "000000000"        # ваш Telegram ID (число)
```

**3. Запустите:**

```bash
docker compose pull
docker compose up -d
```

**4. Напишите боту `/start`** — откроется мастер настройки: язык, база данных, подключение к панели.

Что нужно на сервере и права API-токена панели — [«Что нужно перед стартом»](https://remna.shop/start/requirements/), подробности установки — [«Установка»](https://remna.shop/start/install/).

## Образы и каналы

| Канал | Ветка | Образ |
|---|---|---|
| Stable | `main` | `ghcr.io/mrvibecodic/chill-remna-bot:latest` |
| Dev (превью) | `dev` | `ghcr.io/mrvibecodic/chill-remna-bot:dev` |
| Релиз | тег `vX.Y.Z` | `…:v1.2.3`, `…:v1.2`, `…:v1` |

В `docker-compose.yml` по умолчанию стоит `:v1` — приходят все релизы `1.x.y`. Канал переключается в боте: **Система → 🌿 Канал**. Подробнее — [«Каналы релизов»](https://remna.shop/ops/channels/).

## Обновление и бэкап

Обновление — кнопкой **Система → ⬆️ Обновить** или командой `/update` в боте (или `docker compose pull && docker compose up -d`). Бэкапить нужно том `bot-data`: `bot.db` (если SQLite) и `secret.key` — без ключа настройки не расшифровать. На PostgreSQL добавьте дамп базы. Подробности — [«Обновление и бэкап»](https://remna.shop/ops/update/).

## Документация: как править

Сайт документации живёт в этом же репозитории, в папке `site/` (Astro + Starlight). Страницы — обычный markdown в `site/src/content/docs/**`, меню — в `site/astro.config.mjs`. После пуша в `main` GitHub Actions собирает сайт и публикует его на remna.shop.

Локально:

```bash
cd site
npm ci
npm run dev     # http://localhost:4321
```
