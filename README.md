# Chill Remna bot

[![Telegram — группа](https://img.shields.io/badge/Telegram-%D0%93%D1%80%D1%83%D0%BF%D0%BF%D0%B0-2AABEE?style=for-the-badge&logo=telegram&logoColor=white)](https://t.me/+2lmP1yhxpCE3MDcy)
[![Telegram — чат](https://img.shields.io/badge/Telegram-%D0%A7%D0%B0%D1%82-229ED9?style=for-the-badge&logo=telegram&logoColor=white)](https://t.me/+8BJQXYXYLqM4YWYy)

Телеграм-бот для панели **Remnawave**: магазин подписок и админка в одном чате. Пользователь выбирает тариф, оплачивает и за пару минут получает ключ. Вся настройка — в Telegram: на сервере вписываются два значения и запускается одна команда.

Работает в Docker на обычных серверах и на ARM. База — SQLite или PostgreSQL (PostgreSQL бот поднимает сам). Настройки хранятся в базе зашифрованными.

> 📖 **Документация: https://remna.shop/** — установка, настройка, платёжки, обновление, FAQ и скриншоты.

## Коротко о возможностях

- **Тарифы** — сколько угодно, у каждого свои сроки, цены, трафик и лимит устройств. При смене тарифа остаток не сгорает.
- **Оплаты** — перевод на карту, Telegram Stars, ЮKassa (с автопродлением), CryptoBot, Platega, Heleket, Tribute, ЮMoney. Каждый способ включается отдельно. Если уведомление об оплате ЮKassa, CryptoBot, Platega, Heleket или ЮMoney потерялось, бот перепроверит её сам.
- **Кошелёк, промокоды, рефералка** — баланс в рублях, промокоды на деньги, дни или трафик, бонус за приглашение и процент с оплат друга.
- **Триал и напоминания** — пробный период, в том числе аккаунтам по почте; напоминания о сроке и предупреждение о расходе трафика.
- **Мини-апп и веб-кабинет** — то же самое приложением в Telegram и сайтом. Вход через Telegram или по почте. Экран «Подключить» с приложениями под все платформы и разделами инструкции. Два дизайна, своё название, цвет и логотип.
- **Свои тексты и картинки** — сообщения, кнопки, письма и картинки разделов меняются прямо в боте.
- **Админка в чате** — продажи, маркетинг, интерфейс, пользователи, система.
- **Безопасность** — автоблок скам-регистраций, режимы доступа (публично / по приглашениям / белый список). В панели бот меняет только своих пользователей.

Подробнее — [«Введение»](https://remna.shop/start/features/).

## Установка за 4 шага

**1. Возьмите `docker-compose.yml`:**

```bash
mkdir -p /opt/remnachillbot && cd /opt/remnachillbot
curl -fsSL -o docker-compose.yml \
  https://raw.githubusercontent.com/Mrvibecodic/chill-remna-bot/main/docker-compose.yml
```

**2. Впишите два значения** (`nano docker-compose.yml`):

```yaml
      BOT_TOKEN: "123456789:AAEabc..."     # токен от @BotFather
      ADMIN_TELEGRAM_ID: "000000000"        # ваш Telegram ID (число)
```

**3. Запустите:**

```bash
docker compose up -d
```

**4. Напишите боту `/start`** — откроется мастер настройки: язык, база данных, подключение к панели.

Что нужно на сервере и права API-токена панели — [«Что подготовить»](https://remna.shop/start/requirements/), подробности — [«Установка»](https://remna.shop/start/install/).

## Обновление и бэкап

Обновление — кнопкой **Система → ⬆️ Обновить** или командой `/update` в боте (или `docker compose pull && docker compose up -d`). В `docker-compose.yml` стоит образ `:v1` — приходят все релизы `1.x.y`; канал переключается в боте: **Система → 🌿 Канал**, подробнее — [«Каналы релизов»](https://remna.shop/ops/channels/).

Бэкап — **Система → 💾 Бэкап базы**: бот присылает файл со всей базой по расписанию и восстанавливает её из файла, в том числе на новом сервере. Подробности — [«Обновление и бэкап»](https://remna.shop/ops/update/).
