## Обновление

Проще всего — команда **`/update`** боту или кнопка **Система → ⬆️ Обновить**. Бот скачает свежий образ, перезапустится и напишет, чем всё закончилось.

Вручную:

```bash
cd /opt/remnachillbot
docker compose pull
docker compose up -d
```

В **Система** есть ещё **🔍 Проверить** (есть ли новая версия) и **🔔 Уведомления** — раз в день бот сам сообщит, если вышло обновление. При первой проверке бот попросит выбрать канал.

## Версии и каналы

По умолчанию в `docker-compose.yml` стоит тег `:v1` — приходят все релизы 1.x.y. Чтобы остаться на одной версии, впишите вместо него конкретную, например `:v1.8.0`: обновления перестанут приходить, пока не смените тег. Все варианты тегов и переключение Stable/Dev — в разделе [«Каналы релизов»](/ops/channels/). Что нового в каждой версии — на [странице релизов](https://github.com/Mrvibecodic/chill-remna-bot/releases).

## Бэкап

- **SQLite:** сохраните том `bot-data` целиком — в нём и база, и `secret.key`.
- **PostgreSQL:** снимите дамп базы и тоже сохраните том `bot-data`:
  ```bash
  docker exec remnabot-db pg_dump -U remnabot remnabot > backup_$(date +%F).sql
  ```

:::caution
Без `secret.key` восстановленная база бесполезна: настройки в ней зашифрованы. Храните ключ вместе с бэкапом. Если ключ задан переменной `SECRET_KEY`, сохраните её значение.
:::

## Переезд с remnashop

Если вы продавали подписки через [remnashop](https://github.com/snoups/remnashop), перенести базу можно мастером **Система → 📦 Переезд с remnashop**.

1. В remnashop: **Дашборд → Бэкап** → создайте бэкап базы. Подойдёт и обычный текстовый `pg_dump`.
2. Файл больше 20 МБ сожмите: `gzip db_backup.sql` — крупнее Telegram боту не отдаст.
3. В нашем боте: **📦 Переезд с remnashop → 📥 Загрузить дамп** и пришлите файл.
4. Бот покажет, что нашёл, — нажмите **✅ Импортировать**.

**Что переносится:**

- пользователи с Telegram ID (имя, username, блокировка);
- сроки подписок — дальше по ним работают напоминания;
- отметка «триал использован» — второй раз бесплатный период не выдастся;
- реферальные баллы → баланс кошелька, 1 балл = 1 ₽;
- кто кого пригласил (бонус считается уже выплаченным);
- промокоды на дни и их активации;
- история успешных платежей — для статистики.

**Что не переносится:** настройки, тарифы, платёжки, рассылки и веб-аккаунты без Telegram ID (их вход придётся создать заново). Промокоды на трафик, устройства и скидку пропускаются — бот перечислит их перед импортом.

**Версии.** Подходят remnashop **v0.8.0–v0.8.2**. Дамп более старой версии бот отклонит: обновите remnashop до 0.8.x и снимите бэкап заново.

**Панель трогать не нужно.** Учётки в ней остаются как есть — бот найдёт их при первом заходе человека, продления пойдут в ту же учётку, дублей не будет. Панель может быть 2.7.4+ или 3.x. Если собираетесь обновлять панель до 3.x, сначала снимите дамп remnashop и импортируйте его, потом обновляйте панель.

**Если бот закрыт** (приглашения или белый список), импортированные пользователи приходят без доступа — выдайте его в **Пользователи → 🚪 Доступ** или в карточке, иначе они не войдут.

**Импорт ничего не удаляет и не уменьшает.** У тех, кто уже есть в боте, заполняются только пустые поля: срок подписки только продлевается, баланс начисляется один раз и только новым, блокировка из remnashop ставится только новым. Кого нет в дампе, импорт не трогает. Повторная загрузка того же дампа ничего не задваивает.
