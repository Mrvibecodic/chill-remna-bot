## Обновление

**Из бота.** Команда **`/update`** или кнопка **Система → ⬆️ Обновить**. Бот скачивает свежий образ, перезапускается и сообщает результат.

**Вручную:**

```bash
cd /opt/remnachillbot
docker compose pull
docker compose up -d
```

В разделе **Система** есть ещё две кнопки:

- **🔍 Проверить** — есть ли новая версия;
- **🔔 Уведомления** — раз в день бот сообщает о вышедшем обновлении. При первой проверке бот спрашивает канал.

## Версии и каналы

В `docker-compose.yml` стоит тег `:v1` — приходят все релизы 1.x.y. С конкретной версией вместо него, например `:v1.8.0`, обновления не приходят, пока тег не изменён.

- Все теги и переключение Stable / Dev — [Каналы релизов](/ops/channels/).
- Изменения в каждой версии — [страница релизов](https://github.com/Mrvibecodic/chill-remna-bot/releases).

## Бэкап

**Из бота.** **Система → 💾 Бэкап базы**: бот присылает файл со всей базой по расписанию. Восстановление — из того же раздела, в том числе на новом сервере. Нужны только файл и пароль бэкапа. Подробно — [Бэкап базы](/admin/system/#bekap-bazy).

**Вручную:**

- **SQLite** — том `bot-data` целиком: в нём база и `secret.key`.
- **PostgreSQL** — дамп базы и том `bot-data`:
  ```bash
  docker exec remnabot-db pg_dump -U remnabot remnabot > backup_$(date +%F).sql
  ```

:::caution
Без `secret.key` восстановленная вручную база бесполезна: настройки в ней зашифрованы. Ключ хранится вместе с бэкапом. Если ключ задан переменной `SECRET_KEY`, сохраняется её значение.
:::

## Переезд с remnashop

База бота [remnashop](https://github.com/snoups/remnashop) переносится мастером **Система → 📦 Переезд с remnashop**.

1. В remnashop: **Дашборд → Бэкап** → создать бэкап базы. Подходит и обычный текстовый `pg_dump`.
2. Файл больше 20 МБ нужно сжать: `gzip db_backup.sql`. Крупнее Telegram боту не отдаёт.
3. В боте: **📦 Переезд с remnashop → 📥 Загрузить дамп** — отправить файл боту.
4. Бот показывает, что нашёл. **✅ Импортировать** запускает перенос.

### Что переносится

- пользователи с Telegram ID: имя, username, блокировка;
- сроки подписок — по ним работают напоминания;
- отметка «триал использован» — бесплатный период второй раз не выдаётся;
- реферальные баллы → баланс кошелька, 1 балл = 1 ₽;
- кто кого пригласил; бонус считается выплаченным;
- промокоды на дни и их активации;
- история успешных платежей — для статистики.

### Что не переносится

- настройки, тарифы, способы оплаты, рассылки;
- веб-аккаунты без Telegram ID — их вход создаётся заново;
- промокоды на трафик, устройства и скидку — бот перечисляет их перед импортом.

### Условия

| Вопрос | Ответ |
|---|---|
| Версии remnashop | **v0.8.0–v0.8.2**. Дамп более старой версии бот отклоняет: нужно обновить remnashop до 0.8.x и снять бэкап заново. |
| Панель | Не меняется. Бот находит учётки при первом заходе человека, продления идут в ту же учётку, дублей нет. Версия панели — 2.7.4+ или 3.x. |
| Обновление панели до 3.x | Сначала дамп remnashop и импорт, потом обновление панели. |
| Закрытый бот | В режимах «по приглашениям» и «белый список» импортированные пользователи приходят без доступа. Доступ им выдаётся в **Пользователи → 🚪 Доступ** или в карточке пользователя. |

Импорт ничего не удаляет и не уменьшает:

- у тех, кто уже есть в боте, заполняются только пустые поля;
- срок подписки только продлевается;
- баланс начисляется один раз и только новым;
- блокировка из remnashop ставится только новым;
- тех, кого нет в дампе, импорт не затрагивает;
- повторная загрузка того же дампа ничего не удваивает.
