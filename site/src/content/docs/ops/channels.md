Образ бота — `ghcr.io/mrvibecodic/chill-remna-bot`, для amd64 и arm64. Какие обновления приходят, определяет тег образа в `docker-compose.yml`.

| Тег | Что приходит |
|---|---|
| `:v1` | Все релизы 1.x.y, без перехода на будущий 2.0.0. **Стоит по умолчанию.** |
| `:latest` | Последняя стабильная версия. |
| `:v1.8` (пример) | Только исправления одной линии, здесь 1.8.x. |
| `:v1.8.0` (пример) | Ровно эта версия, без обновлений. |
| `:dev` | Тестовая ветка: новое появляется раньше, возможны ошибки. |

Все теги, кроме `:dev`, — канал <span class="tag stable">Stable</span>. Тег `:dev` — канал <span class="tag dev">Dev</span>.

Список изменений каждой версии — [страница релизов](https://github.com/Mrvibecodic/chill-remna-bot/releases).

## Переключение в боте

**Система → 🌿 Канал** → 🟢 Stable или 🧪 Dev. При следующем обновлении бот сам меняет тег в `docker-compose.yml`.

| Действие | Что делает бот с тегом |
|---|---|
| Выбран Dev | Ставит `:dev`. |
| Возврат на Stable с `:dev` | Ставит `:latest`. |
| В Stable стоит `:v1`, `:v1.8` или `:v1.8.0` | Не меняет. |

:::note
Данные при смене канала сохраняются — они в томе `bot-data`. Если Dev ушёл вперёд, возврат на Stable означает откат на более старую версию.
:::
