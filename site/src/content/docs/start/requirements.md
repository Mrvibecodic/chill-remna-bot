До установки нужны пять вещей.

## 1. Сервер с Docker

Linux (Ubuntu или Debian), x86-64 или ARM64, с **Docker** и **Docker Compose v2**. Проверка:

```bash
docker version
docker compose version
```

Команд нет — поставьте Docker по [официальной инструкции](https://docs.docker.com/engine/install/).

Сколько нужно памяти и диска — в [Требованиях к серверу](/start/server/).

## 2. Панель Remnawave

Версия **2.7.4 или новее**, включая 3.x. Бот подключается к панели, но не ставит её. Версию определяет сам — панель и бота можно обновлять в любом порядке.

## 3. Токен бота

1. Откройте [@BotFather](https://t.me/BotFather).
2. Отправьте `/newbot` и придумайте боту имя.
3. Скопируйте строку вида `123456789:AAEabc...` — это и есть токен (`BOT_TOKEN`).

## 4. Ваш Telegram ID

Число, его пришлёт [@userinfobot](https://t.me/userinfobot). Это `ADMIN_TELEGRAM_ID`: админка доступна только этому аккаунту.

## 5. Ключ доступа к панели (API-токен)

Создайте в дашборде панели (роль API). Вписывать в файл не нужно — бот спросит его в мастере.

:::note[Панель 2.8.0 и новее]
У токена есть список прав. Возьмите готовый список из [Права токена панели](/reference/panel-scopes/): без обязательных прав бот не пройдёт проверку связи. Старые токены при обновлении панели получают полный доступ сами.
:::
