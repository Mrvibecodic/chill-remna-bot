---
title: Что нужно перед стартом
description: Сервер с Docker, панель Remnawave, токен бота, Telegram ID администратора и API-токен панели.
---

1. **Сервер с Linux** (подойдут Ubuntu и Debian) на x86-64 или ARM64, с **Docker** и **Docker Compose v2**. Проверка:
   ```bash
   docker version
   docker compose version
   ```
   Если команд нет — поставьте Docker по [официальной инструкции](https://docs.docker.com/engine/install/).

   Сколько нужно процессора, памяти и диска — в [Требованиях к серверу](/start/server/).

2. **Работающая панель Remnawave 2.7.4 или новее, включая 3.x.** Бот к ней подключается, но не ставит её. Версию панели бот определяет сам, так что обновлять панель и бота можно в любом порядке.

3. **Токен бота.** В [@BotFather](https://t.me/BotFather) отправьте `/newbot`, задайте имя и получите строку вида `123456789:AAEabc...` — это `BOT_TOKEN`.

4. **Ваш Telegram ID** — число, его пришлёт [@userinfobot](https://t.me/userinfobot). Это `ADMIN_TELEGRAM_ID`: у этого аккаунта будет доступ в админку.

5. **API-токен панели** — создайте в дашборде панели (роль API). В файл его вписывать не нужно, вы введёте его в мастере.
   На панели **3.x** у токена есть права (скоупы). Старые токены при обновлении панели получают их сами, а для нового возьмите готовый список из [Права токена панели](/reference/panel-scopes/) — без обязательного минимума бот не пройдёт проверку связи.
