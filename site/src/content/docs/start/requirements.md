До установки нужны пять вещей.

## 1. Сервер с Docker

Linux (Ubuntu или Debian), x86-64 или ARM64, с **Docker** и **Docker Compose v2**. Проверка:

```bash
docker version
docker compose version
```

Если команд нет, Docker нужно поставить по [официальной инструкции](https://docs.docker.com/engine/install/).

Память, процессор и диск — [Требования к серверу](/start/server/).

## 2. Панель Remnawave

Версия **2.7.4 или новее**, включая 3.x. Бот подключается к установленной панели и сам определяет её версию. Панель и бот обновляются в любом порядке.

## 3. Токен бота

1. Открыть [@BotFather](https://t.me/BotFather).
2. Отправить `/newbot` и задать боту имя.
3. Скопировать строку вида `123456789:AAEabc...` — это токен (`BOT_TOKEN`).

## 4. Ваш Telegram ID

Число, его присылает [@userinfobot](https://t.me/userinfobot). Это `ADMIN_TELEGRAM_ID`: админка доступна только этому аккаунту.

## 5. Ключ доступа к панели (API-токен)

Токен создаётся в дашборде панели (роль API). В файл его вписывать не нужно — бот спрашивает его в мастере.

:::note[Панель 2.8.0 и новее]
У токена есть список прав. Готовый список — [Права токена панели](/reference/panel-scopes/). Без обязательных прав бот не проходит проверку связи. Старые токены при обновлении панели получают полный доступ сами.
:::
