После первого `/start` бот задаёт вопросы по шагам.

1. **Язык** — 🇷🇺 Русский или 🇬🇧 English. Меняется в **Интерфейс → 🌐 Язык бота**.

2. **База данных:**
   - **📄 SQLite** — база в одном файле, отдельная установка не нужна.
   - **🐘 PostgreSQL 17** — отдельный контейнер. Бот поднимает его в Docker сам и переключается без перезапуска. Если не получилось — остаётся на SQLite. Без доступа к Docker бот спрашивает строку подключения к готовому PostgreSQL.

3. **Где бот относительно панели:**
   - **🏠 Локально** — на одном сервере с панелью. Бот подключается к её Docker-сети, адрес панели не вводится.
   - **🌐 Удалённо** — на другом сервере. Бот обращается к панели по её HTTPS-домену.

4. **Как установлена панель** (только для «Удалённо»):
   - **📘 Официально (по доке)** — бот спрашивает, закрыт ли путь `/api` защитой Caddy. Если закрыт — просит X-API-Key.
   - **🛠 Скрипт eGames (nginx)** — бот просит куку защиты.

5. **Данные для подключения:**
   - **URL панели** — только для «Удалённо», например `https://panel.example.com`.
   - **API-token панели** — из дашборда панели: [Что подготовить](/start/requirements/).
   - **Кука** (eGames) — пара `ИМЯ=ЗНАЧЕНИЕ`. Она есть в ссылке входа от установщика (`https://ВАШ-ДОМЕН/auth/login?ИМЯ=ЗНАЧЕНИЕ`) и в файле `/opt/remnawave/nginx.conf` на сервере панели.
   - **X-API-Key** — если панель закрыта аддоном [«Caddy with security»](https://docs.rw/install/panel-security/). Ключ выдаётся в портале аддона, раздел API-keys. Если ключ вписан в `CADDY_AUTH_API_TOKEN` в `docker-compose.yml`, мастер про него не спрашивает.

6. **Проверка связи** — бот обращается к панели и показывает, сколько в ней пользователей. Число пришло — настройка закончена, кнопка «🛠 Открыть админ-панель» открывает админку.

Если проверка не прошла, мастер запускается заново командой `/setup`.

Следующий шаг — [После установки](/start/after-install/).

## Изменить настройки потом

- Адрес панели, токен, ключ и кука — **Система → 🔌 Подключение к панели**: [подробнее](/admin/system/#podklyuchenie-k-paneli).
- База данных и подключение целиком — **Система → 🔧 Перенастроить** или `/setup`. Мастер начинается с выбора базы. Текущие настройки сохраняются, при смене базы данные переносятся в новую.

Всё введённое хранится в базе в зашифрованном виде и сохраняется при перезапуске.
