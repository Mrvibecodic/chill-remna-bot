После мастера бот подключён к панели. Продажи начинаются, когда есть тариф с ценой и включён хотя бы один способ оплаты.

## Тариф

**💸 Продажи → 🪄 Быстрая настройка тарифов** — пять шагов: срок, цена, трафик, устройства, сквады. Результат — тариф «Базовый».

Все настройки тарифов — [Продажи](/admin/sales/#tarify).

## Способ оплаты

Каждый способ включается на своём экране в **💸 Продажи**.

| Способ | Что нужно для работы |
|---|---|
| 🤝 P2P (перевод на карту) | номер карты; оплату подтверждает администратор |
| ⭐ Telegram Stars | цена в звёздах |
| ЮKassa, CryptoBot, Platega, Heleket, Tribute, ЮMoney | ключи платёжной системы и адрес бота с HTTPS |

Описание способов — [Способы оплаты](/start/features/#sposoby-oplaty).

## Адрес бота с HTTPS

На этот адрес платёжные системы присылают уведомления об оплате. Он же нужен мини-аппу и веб-кабинету. P2P и Telegram Stars работают без него.

Настройка — [Вебхуки и свой домен](/payments/webhooks/).
