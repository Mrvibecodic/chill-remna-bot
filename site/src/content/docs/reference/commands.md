---
title: Команды бота
description: Команды бота для пользователя и администратора.
---

| Команда | Кому | Действие |
|---|---|---|
| `/start` | всем | старт; новый пользователь регистрируется автоматически и сразу видит меню |
| `/buy` | всем | сразу открыть выбор тарифа |
| `/support`, `/paysupport` | всем | контакт поддержки (по чек-листу Telegram для Stars) |
| `/terms`, `/privacy`, `/docs` | всем | документы сервиса: соглашение и политика конфиденциальности |
| `/status` | админу | связь с панелью + краткая статистика и ресурсы |
| `/setup` | админу | пройти мастер настройки заново |
| `/update` | админу | скачать свежий образ из GHCR и перезапуститься (`docker compose pull` + `up -d`, через одноразовый контейнер-контроллер) |
| `/p2p`, `/emoji`, `/welcome` | админу | быстрый вход в настройку P2P / премиум-эмодзи / баннера |
