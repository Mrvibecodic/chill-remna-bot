---
title: Команды бота
description: Команды бота для пользователя и администратора.
---

## Для всех

| Команда | Что делает |
|---|---|
| `/start` | Открывает главное меню. Новый пользователь регистрируется сам. |
| `/buy` | Открывает выбор тарифа. |
| `/support`, `/paysupport` | Показывает контакт поддержки. |
| `/terms`, `/privacy`, `/docs` | Показывает документы сервиса: соглашение и политику конфиденциальности. |

## Для администратора

| Команда | Что делает |
|---|---|
| `/start` | Открывает меню администратора. На ненастроенном боте запускает мастер. |
| `/status` | Показывает связь с панелью, число пользователей, базу, способы оплаты и ресурсы сервера. |
| `/setup` | Запускает мастер заново. Текущие настройки берутся за основу и не обнуляются. |
| `/update` | Скачивает свежий образ бота и перезапускает его. |
| `/p2p` | Открывает настройки P2P-оплаты. |
| `/emoji` | Открывает премиум-эмодзи. |
| `/welcome` | Открывает баннер главной: картинку и текст. |
