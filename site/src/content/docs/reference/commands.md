---
title: Команды бота
description: Команды бота для пользователя и администратора.
---

| Команда | Кому | Что делает |
|---|---|---|
| `/start` | всем | открыть главное меню; новый пользователь регистрируется сам. На ненастроенном боте запускает мастер (только у админа) |
| `/buy` | всем | сразу открыть выбор тарифа |
| `/support`, `/paysupport` | всем | контакт поддержки |
| `/terms`, `/privacy`, `/docs` | всем | документы сервиса: соглашение и политика конфиденциальности |
| `/status` | админу | связь с панелью, число пользователей, база, способы оплаты и ресурсы сервера |
| `/setup` | админу | пройти мастер заново. Текущие настройки берутся за основу — ничего не обнуляется |
| `/update` | админу | скачать свежий образ бота и перезапуститься |
| `/p2p` | админу | настройки P2P-оплаты |
| `/emoji` | админу | премиум-эмодзи |
| `/welcome` | админу | баннер главной: картинка и текст |
