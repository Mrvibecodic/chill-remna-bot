Переменные задаются в `docker-compose.yml`. Обязательны первые две.

## Основные

| Переменная | Обяз. | По умолчанию | Что делает |
|---|:---:|---|---|
| `BOT_TOKEN` | ✅ | — | Токен бота от @BotFather. |
| `ADMIN_TELEGRAM_ID` | ✅ | — | Telegram ID администратора (число). Только этому аккаунту доступна админка. |
| `DATA_DIR` | | `/data` | Папка данных в контейнере (том `bot-data`). |
| `DB_KIND` | | — | `sqlite` или `postgres` — выбор базы без мастера. Действует, пока база ещё не выбрана. |
| `DATABASE_URL` | | — | Строка подключения к своему PostgreSQL (`postgres://…`). Нужна, если бот не может сам поднять PostgreSQL рядом с собой. |
| `SECRET_KEY` | | — | Ключ шифрования настроек. Если не задан, бот создаёт его сам — файл `secret.key` в папке данных. |
| `LOG_LEVEL` | | `info` | `debug` / `info` / `warn` / `error`. На `debug` в лог пишутся платежи: Telegram ID и суммы. |
| `PREMIUM_EMOJI` | | — | Премиум-эмодзи вида `✅=id,⏳=id`. То же настраивается командой `/emoji`; заданное там главнее. |
| `CUSTOM_STATIC_DIR` | | `/custom` | Папка со [своим дизайном](#svoy-dizayn-mini-appa-i-veb-kabineta) мини-аппа и кабинета. |

:::caution[Ключ шифрования]
Без `SECRET_KEY` или файла `secret.key` из тома `bot-data` сохранённые настройки не расшифровываются. Ключ переносится и бэкапится вместе с базой.
:::

## Прокси и HTTPS

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `TRUSTED_PROXIES` | — | Адреса или сети прокси через запятую: `203.0.113.9, 2001:db8::/32`. Нужна, только если прокси стоит на **другом сервере с публичным IP**. Прокси на той же машине или в docker-сети считается своим и без неё. Без переменной такой прокси не принимается: кабинет уходит в бесконечный редирект на HTTPS, API отвечает `426`. |
| `ALLOW_PLAIN_HTTP` | — | `1` — отключает требование HTTPS. Временная мера на случай, когда прокси не передаёт `X-Forwarded-Proto`. |
| `CADDY_AUTH_API_TOKEN` | — | Ключ `X-Api-Key`, если панель закрыта аддоном [«Caddy with security»](https://docs.rw/install/panel-security/). Главнее ключа, введённого в админке. |

## Docker

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `COMPOSE_FILE_PATH` | `/compose/docker-compose.yml` | Где внутри контейнера лежит compose-файл. Нужен для `/update`, PostgreSQL и портов. |
| `COMPOSE_PROJECT` | `remnachillbot` | Имя проекта docker compose. |
| `COMPOSE_HOST_DIR` | `/opt/remnachillbot` | Папка бота **на сервере**. |
| `PANEL_CONTAINER` | `remnawave` | Имя контейнера панели. К её сети бот подключается в режиме «Локально». |
| `PANEL_NETWORK` | `remnawave-network` | Сеть панели — на случай, если контейнер панели не найден. |
| `SELF_CONTAINER` | `remnabot` | Имя контейнера бота. По нему прокси панели находит бота. |

## Свой дизайн мини-аппа и веб-кабинета

Встроенный интерфейс можно заменить своим: для этого папка с файлами монтируется в контейнер. В `docker-compose.yml` есть готовая закомментированная строка:

```yaml
    volumes:
      - /opt/remnachillbot/custom:/custom:ro
```

- Файл из папки заменяет одноимённый встроенный. Новые файлы (css, js, картинки) становятся доступны рядом.
- `index.html` — общий для мини-аппа и кабинета. `miniapp.html` и `cabinet.html` — только для одного из них.
- Своя страница главнее дизайна, выбранного в админке.
- Правки видны сразу, без перезапуска.
- Заголовок, описание и favicon кабинета из админки подставляются и в свой HTML.
- Общие функции двух встроенных дизайнов лежат в [`shared.js`](https://github.com/Mrvibecodic/chill-remna-bot/blob/main/internal/web/miniapp_static/shared.js). Бот вставляет их в страницу на место метки `/*SHARED*/` — и во встроенную, и в свою. Страница без метки отдаётся как есть.

**Чат поддержки.** [Чат](/admin/system/#chat-podderzhki-v-kabinete) из админки работает и в своей странице, если она сделана из свежей копии встроенной: чат подключает код самой страницы. В старой копии этого кода нет. Его можно добавить двумя способами: обновить копию по встроенной странице или вставить код чата вручную. Нужен один из способов, иначе окон чата будет два.

:::caution[Логика внутри страницы]
Вход, покупка и оплата работают в JS внутри страницы. Основа для своей страницы — копия встроенной: [`index.html`](https://github.com/Mrvibecodic/chill-remna-bot/blob/main/internal/web/miniapp_static/index.html) или [`minimal.html`](https://github.com/Mrvibecodic/chill-remna-bot/blob/main/internal/web/miniapp_static/minimal.html), в которой меняются стили и вёрстка. После обновления бота свою страницу нужно сверить с новой версией встроенной.
:::
