---
title: "Админка: обзор"
description: Структура меню администратора в Telegram и что где настраивается.
---

Откройте меню админа — вы увидите его автоматически, так как ваш ID указан в `ADMIN_TELEGRAM_ID`.

```
[💸 Продажи]    [📣 Маркетинг]
[🎨 Интерфейс]  [👥 Пользователи]
[🛠 Система]
[🛒 Витрина (как видит юзер)]
```

| Раздел | Что внутри |
|---|---|
| [💸 Продажи](/admin/sales/) | Тарифы, сроки и цены, триал, сквады, способы оплаты, кошелёк, история платежей и аналитика, чеки самозанятого, доп-подписка |
| [📣 Маркетинг](/admin/marketing/) | Промокоды, реферальная программа, рассылка, автонапоминания |
| [🎨 Интерфейс](/admin/interface/) | Баннеры разделов, премиум-эмодзи, контакты, документы сервиса |
| [👥 Пользователи](/admin/users/) | Поиск и карточки, блокировки и вайтлист, режимы доступа, торрент-блокер |
| [🛠 Система](/admin/system/) | Статус панели, обновление, вебхуки, мини-апп и веб-кабинет, поддомен подписок, лог API |
| 🛒 Витрина | Посмотреть бота глазами обычного пользователя, не выходя из админки |

Все настройки правятся прямо в Telegram и хранятся в базе в зашифрованном виде — конфигурационных файлов на сервере править не нужно.
