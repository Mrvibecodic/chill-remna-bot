---
title: "Админка: обзор"
description: Структура меню администратора в Telegram и что где настраивается.
---

Меню админа открывается по `/start` у того, чей ID указан в `ADMIN_TELEGRAM_ID`.

```
[💸 Продажи]    [📣 Маркетинг]
[🎨 Интерфейс]  [👥 Пользователи]
[🛠 Система]    [🛒 Витрина]
```

| Раздел | Что внутри |
|---|---|
| [💸 Продажи](/admin/sales/) | Тарифы, цены, триал, сквады, способы оплаты, кошелёк, история платежей, аналитика, чеки самозанятого, доп-подписка |
| [📣 Маркетинг](/admin/marketing/) | Промокоды, рефералка, рассылка, напоминания |
| [🎨 Интерфейс](/admin/interface/) | Баннеры, премиум-эмодзи, контакты и документы, [тексты бота](/admin/texts/), устройства, дизайн мини-аппа и кабинета, язык бота |
| [👥 Пользователи](/admin/users/) | Поиск и карточки, блокировки, режимы доступа и вайтлист, торрент-блокер |
| [🛠 Система](/admin/system/) | Обновление, статус, лог API, вебхуки, подключение к панели, Mini App, веб-кабинет, почта, переезд с remnashop |
| 🛒 Витрина | Бот глазами покупателя, не выходя из админки |

Все настройки меняются прямо в Telegram и хранятся в базе в зашифрованном виде — править файлы на сервере не нужно.
