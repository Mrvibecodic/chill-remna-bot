Меню администратора открывается по `/start` у аккаунта, чей ID указан в `ADMIN_TELEGRAM_ID`.

<div class="docs-cards not-content">
  <a class="docs-card" data-icon="cart" href="/admin/sales/"><b>💸 Продажи</b><span>Тарифы, цены, триал, сквады, способы оплаты, кошелёк, история платежей, аналитика, чеки самозанятого, доп-подписка.</span></a>
  <a class="docs-card" data-icon="megaphone" href="/admin/marketing/"><b>📣 Маркетинг</b><span>Промокоды, рефералка, рассылка, напоминания.</span></a>
  <a class="docs-card" data-icon="layout" href="/admin/interface/"><b>🎨 Интерфейс</b><span>Баннеры, премиум-эмодзи, контакты и документы, тексты бота, устройства, дизайн мини-аппа и кабинета, язык.</span></a>
  <a class="docs-card" data-icon="users" href="/admin/users/"><b>👥 Пользователи</b><span>Поиск и карточки, блокировки, режимы доступа и вайтлист, торрент-блокер.</span></a>
  <a class="docs-card" data-icon="cog" href="/admin/system/"><b>🛠 Система</b><span>Обновление, статус, лог API, вебхуки, подключение к панели, Mini App, веб-кабинет, почта, бэкап базы, переезд с remnashop.</span></a>
  <div class="docs-card" data-icon="image"><b>🛒 Витрина</b><span>Бот глазами покупателя, не выходя из админки.</span></div>
</div>

Все настройки меняются в Telegram и хранятся в базе в зашифрованном виде. Файлы на сервере для этого не правятся.

Свои тексты сообщений, кнопок и писем — отдельная страница: [Тексты бота](/admin/texts/).
