## 💾 Бэкап базы

**Система → 💾 Бэкап базы.** Бот присылает полную копию своей базы одним файлом: пользователи, подписки, оплаты, тарифы, промокоды и все настройки. Подписки в панели в файл не входят — они хранятся в панели.

### Настройка

1. **🔑 Пароль** — от 8 символов. Без пароля файл не открывается. Пока пароль не задан, бэкапы не делаются.
2. **Расписание** — раз в 1, 2, 4, 6, 12 или 24 часа. Отсчёт идёт от последнего бэкапа и не сбивается при перезапуске.
3. **📨 Куда слать** — один из трёх вариантов:

| Вариант | Как работает |
|---|---|
| 👤 Мне | Файл приходит в личный чат — с этим ботом или с отдельным, если он выбран. Под файлом кнопка **🗑 Убрать**; сам бот файлы не удаляет. Сообщения старше 48 часов Telegram не даёт боту удалить. |
| 💬 Группа или канал | Нужен id чата: он отрицательный и начинается с `-100`. Бот должен состоять в чате и иметь право писать. |
| 🤖 Отдельный бот | Нужен второй бот: создать его в @BotFather, нажать в нём «Запустить» и отправить его токен основному боту. Файлы присылает отдельный бот. |

Перед сохранением настроек бот отправляет пробное сообщение туда, куда будут уходить файлы. **💾 Сделать сейчас** — внеочередной бэкап.

### Восстановление

1. **♻️ Восстановить** → отправить боту файл (до 20 МБ). Файл из другого чата или бота можно переслать.
2. Если файл закрыт другим паролем, бот спрашивает его.
3. Бот показывает дату файла и что в нём. До подтверждения база не меняется.
4. **✅ Заменить базу.** Бот присылает бэкап текущей базы, заменяет базу и перезапускается. На это время (пара минут) пользователи видят «техработы», вебхуки платёжных систем получают ответ «попробуйте позже».

Присланный файл ждёт подтверждения 30 минут. Потом его нужно отправить заново.

:::caution[База заменяется целиком]
Пропадает всё, что появилось после даты файла: пользователи, оплаты, пополнения и траты баланса, настройки. Блокировки, пароли кабинета и согласия на автопродление тоже возвращаются к состоянию файла.

Подписки в панели не меняются. Поэтому промокоды и реферальные бонусы, полученные после даты файла, можно получить ещё раз.

Если замена не удалась, база остаётся прежней.
:::

### После восстановления

| Что | Как ведёт себя бот |
|---|---|
| Сроки подписок | Бот сверяет их с панелью. До этого напоминания не отправляются. |
| Автопродление | **Стоит, пока не нажата кнопка «▶️ Включить автопродление»** — кто-то мог отключить его после даты файла. Перед первым списанием у каждого человека бот ещё раз сверяет срок с панелью. |
| Оплаты по старым счетам | Счета, выставленные до восстановления, бот сам не выдаёт: их могли выдать после даты файла. Это касается сверки, старых кнопок «Проверить оплату», повторных уведомлений платёжных систем и оплат звёздами между датой файла и восстановлением. Бот присылает их администратору списком, каждую один раз, а человеку пишет, что оплату проверит администратор. Выдать их можно вручную после проверки в панели. |
| Заявки на перевод из файла | Приходят администратору списком. Перед одобрением нужно проверить, что по ним ещё ничего не выдано. Если сообщение не дошло, бот повторяет. |
| Лимиты подписок | Тем, у кого срок в панели разошёлся с файлом, бот не возвращает лимиты из файла, пока человек не купит снова. |

Настройки бэкапа (пароль, расписание, получатель) хранятся отдельно от остальных. Они сохраняются при откате бота на версию без бэкапов и возврате обратно.

### На новом сервере

Нужны только файл и пароль:

1. Поставить бота с тем же `BOT_TOKEN` и `ADMIN_TELEGRAM_ID`.
2. Пройти мастер.
3. Восстановить базу из файла.

Старый `SECRET_KEY` не нужен. Тип базы (SQLite или PostgreSQL) может отличаться.

### Частые проблемы

| Что видно | Причина и решение |
|---|---|
| «Файл больше 20 МБ» | Telegram не отдаёт ботам такие файлы. Через бота такой бэкап не восстанавливается. |
| «Файл сделан более новой версией бота» | Сначала обновляется бот. |
| Бэкап по расписанию не пришёл | Бот пишет о неудаче и повторяет через час. Причина обычно в том, что он (или отдельный бот) не может писать в выбранный чат. Файл больше 50 МБ повторяется уже по расписанию. |
| Отдельный бот «не может вам написать» | В отдельном боте не нажато «Запустить». |

## 🔌 Подключение к панели

**Система → 🔌 Подключение к панели** — всё, что связывает бота с панелью, без повторного мастера.

| Кнопка | Что задаёт |
|---|---|
| 🌐 Адрес панели | Например `https://panel.example.com`. `https://` подставляется само, `/api` и слэш в конце убираются. Для панели на этом же сервере в общей docker-сети — `http://remnawave:3000`. |
| 🔑 API-token | Новый токен из дашборда Remnawave. Старый токен можно отзывать только после того, как бот подтвердил связь. |
| 🔐 Ключ Caddy · 🍪 Кука eGames | Секреты прокси перед панелью. Видны, если панель на другом сервере или секрет уже задан. Ключ из переменной `CADDY_AUTH_API_TOKEN` здесь не меняется — действует переменная. |
| 🧭 Домен подписки | Свой домен в ссылках подписки. Бот заменяет в ссылке только домен. |

- Адрес и токен проверяются на панели до сохранения.
- Если панель не ответила, есть кнопка **💾 Сохранить без проверки** — для переезда, когда адрес и токен меняются по очереди.
- При смене адреса на другой сервер ключ и кука сбрасываются.
- Сообщения с секретами бот удаляет из чата.

## Mini App и веб-кабинет

Обоим нужен адрес бота с HTTPS — он задаётся в «🔗 Вебхуках».

### Mini App

**Система → 📱 Mini App**, по умолчанию выключен.

1. Включить Mini App.
2. Задать адрес бота в «🔗 Вебхуках».
3. Скопировать адрес мини-аппа с экрана и вставить в @BotFather → Bot Settings → Menu Button.

### Веб-кабинет

**Система → 🌐 Веб-кабинет**, по умолчанию выключен. Это тот же магазин на отдельном сайте, адрес по умолчанию — `https://ваш-домен/cabinet/`. Вход — через Telegram или по почте с паролем. На компьютере меню кабинета стоит слева, на телефоне кабинет выглядит как мини-апп.

| Кнопка | Что делает |
|---|---|
| ✏️ Изменить путь | Адрес кабинета на сайте. |
| 🛡 Telegram · 🛡 Почта | Ручная проверка новых: кто впервые вошёл этим способом, попадает в кабинет после одобрения администратором. Обе выключены — входят все. |
| ✏️ Заголовок · ✏️ Описание · 🖼 Фавикон | Название вкладки, описание для поисковиков и значок. |
| 🕵️ Анти-фингерпринт | Страница кабинета меняется от запроса к запросу, чтобы её было сложнее опознать как этого бота. |
| 🔑 Вход через Telegram | Старый виджет или новый Login Widget Telegram. «Новый» выбирается, если в @BotFather у бота включён новый Login Widget — [как его настроить](/payments/webhooks/#proverka). |
| 💬 Чат на сайте | Окно стороннего чата поддержки — [ниже](#chat-podderzhki-v-kabinete). |
| 🚪 Разлогинить всех | Завершает все сессии кабинета и мини-аппа. |

Триал в кабинете доступен тем, кто вошёл через Telegram, а аккаунтам по почте — если он [включён для почты](/admin/sales/#trial-akkauntam-po-pochte). Внешний вид мини-аппа и кабинета — [Интерфейс → Дизайн мини-аппа и веб-кабинета](/admin/interface/#dizayn-mini-appa-i-veb-kabineta).

### 💬 Чат поддержки в кабинете

В кабинет ставится окно стороннего чата — любого, который подключается к сайту одной строкой `<script src="https://…">`. Пример — виджет [прослойки подписок](https://github.com/Mrvibecodic/remnawave-subscription-middleware).

1. Скопировать в сервисе чата код для вставки на сайт.
2. Открыть **Система → 🌐 Веб-кабинет → 💬 Чат на сайте** и отправить боту этот код или только адрес скрипта. На экране кабинета появляется адрес чата.
3. Кнопкой **👁 Чат** выбрать, где он показывается: **после входа** — только вошедшим, **везде** — ещё и на окне входа.
4. Открыть кабинет в браузере — в нём появляется кнопка чата.

Чтобы убрать чат, вместо кода нужно отправить «-». В мини-аппе в Telegram чат не показывается.

:::caution
Скрипт чата работает на странице кабинета и видит всё, что на ней есть.
:::

**Виджет прослойки.** В админке прослойки на вкладке «Чат поддержки»:

- включить «Виджет для других сайтов»;
- добавить адрес сайта кабинета (`https://ваш-домен`) в «Сайты, где разрешён виджет»;
- выбрать дизайн «Кабинет — классика» или «Кабинет — минимализм».

Код для вставки — на той же вкладке.

«Переотправке в Telegram» в прослойке нужен **отдельный бот**, не этот. Прослойка ставит на токен своего бота вебхук, а бот с вебхуком на токене перестаёт получать сообщения и нажатия кнопок.

Частые проблемы:

| Что видно | Причина и решение |
|---|---|
| Бот отвечает «Адрес скрипта не найден» | Нужен адрес, который начинается с `https://`. Чат, которому кроме адреса нужен свой код на странице, так не подключается. |
| Кнопки чата нет | Причина — в том, где чат показывается (**👁 Чат**), или сайт кабинета не разрешён в настройках самого чата. |
| После подключения чата прослойки бот перестал отвечать | В «Переотправку в Telegram» вписан токен этого бота. Кнопка **🧹 Удалить вебхук** в прослойке снимает вебхук; после этого туда нужно вписать токен отдельного бота. Если токен уже заменён — [Если что-то не работает](/ops/troubleshooting/). |

## ✉️ Почта кабинета

**Система → ✉️ Почта.** Без почты регистрация в кабинете идёт без подтверждения адреса и без восстановления пароля.

С включённой почтой:

- при регистрации **подтверждается адрес**. До подтверждения закрыты покупка, пополнение, промокоды и тарифы «по списку». Вход и просмотр подписки доступны;
- **пароль восстанавливается** по ссылке из письма, ссылка действует час;
- при смене пароля на адрес приходит **уведомление**.

Аккаунты, созданные до включения почты, считаются подтверждёнными.

### Способы отправки

Кнопка **🔀 Способ**.

| Способ | Описание |
|---|---|
| SMTP | Свой сервер или почтовый сервис: Yandex, Mail.ru, SendGrid, Mailgun. Сервер вводится как `smtp.example.com:587`. Без порта подставляется 587 для STARTTLS или 465 для TLS. Вход по паролю без шифрования запрещён. |
| Внешний API | Отправка через HTTPS — на случай, когда хостер закрыл почтовые порты. По умолчанию в формате [Resend](https://resend.com); адрес шлюза меняется. |

**📨 Отправить тестовое** отправляет письмо на адрес отправителя и показывает ошибку сервера целиком.

- Для ссылок в письмах нужен адрес бота с HTTPS (раздел «🔗 Вебхуки»). Без него письма не отправляются.
- На один аккаунт — не чаще одного письма в минуту и не больше пяти в сутки.

## 🔗 Привязка Telegram к аккаунту кабинета

На экране **«Аккаунт»** в кабинете у аккаунта по почте есть кнопка входа через Telegram. После привязки:

- вход работает и через Telegram, и по почте с паролем;
- в строке «Telegram» на экране «Аккаунт» вместо «привязан» стоит @username, а без него — имя;
- в боте видны та же подписка, баланс и история;
- **ссылка подписки не меняется**, приложение переподключать не нужно;
- приглашённые остаются за аккаунтом, разосланные реферальные ссылки работают.

Пока Telegram не привязан, сообщения бота (об оплате, напоминания, рассылка) такому аккаунту не приходят. Подписку и баланс он видит в кабинете.

Ограничения:

- Привязывается только Telegram без своей истории в боте: подписки, платежей, баланса. Две истории покупок автоматически не объединяются, такие случаи решает поддержка.
- В закрытом боте не привязывается Telegram, которому бот закрыт.
