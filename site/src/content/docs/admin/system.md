Статус панели, `/update`, вебхуки, поддомен подписок, лог API-запросов (последние 200), перенастройка (мастер БД и панели заново).

- **📦 Переезд с remnashop** — импорт базы бота [remnashop](https://github.com/snoups/remnashop) в наш бот (см. [«Переезд с remnashop»](/ops/update/#переезд-с-remnashop)).
- **🔄 Проверить обновления** — ручная проверка прямо сейчас.
- **🔔 Уведомления об обновлениях** (тумблер, по умолчанию вкл) — раз в сутки в 12:00 МСК бот сверяет свою версию с GitHub и при новой шлёт админу список новых коммитов (changelog) и кнопку «Обновить». Уведомление приходит **только когда новый образ уже собран CI** (проверка по GitHub Actions), поэтому «Обновить» гарантированно скачает свежий образ и бот перезапустится. Уведомление самоудаляется через 60 секунд. Точное сравнение версий работает с образов, собранных с вшитым commit SHA (через CI).
