Служебные функции раздела **🛠 Система**:

- **⬆️ Обновить** (или команда `/update`) — скачать свежий образ и перезапустить бота. **🔍 Проверить** — проверить наличие обновления прямо сейчас.
- **🔔 Уведомления** (по умолчанию вкл) — раз в сутки в 12:00 МСК бот сверяет версию с GitHub и, если вышло обновление, присылает список изменений и кнопку «Обновить». Уведомление приходит, только когда новый образ уже собран, и само удаляется через минуту.
- **🌿 Канал** — Stable (проверенные релизы) или Dev (новое раньше, но возможны ошибки). Подробнее — [Каналы релизов](/ops/channels/).
- **🩺 Статус** (или `/status`) — связь с панелью и сводка. **📡 Лог API** — последние 200 запросов бота к панели.
- **🔗 Вебхуки** — публичный адрес бота, приём оплат и событий панели, секрет панели. Подробно — [Вебхуки](/payments/webhooks/).
- **🔌 Подключение к панели**, **📱 Mini App**, **🌐 Веб-кабинет**, **✉️ Почта** — ниже.
- **📦 Переезд с remnashop** — перенос базы бота [remnashop](https://github.com/snoups/remnashop), см. [«Переезд с remnashop»](/ops/update/#переезд-с-remnashop).
- **🔧 Перенастроить** — заново пройти мастер базы данных и подключения к панели.

## 🔌 Подключение к панели

**Система → 🔌 Подключение к панели** — всё, что связывает бота с панелью, без повторного мастера:

- **🌐 Адрес панели** — например `https://panel.example.com`. `https://` подставится сам, `/api` и слэш в конце бот уберёт. Если панель на этом же сервере в общей docker-сети, укажите `http://remnawave:3000`.
- **🔑 API-token** — новый токен из дашборда Remnawave. Старый отзывайте только после того, как бот подтвердит связь.
- **🔐 Ключ Caddy** и **🍪 Кука eGames** — секреты прокси перед панелью (видны, если панель на другом сервере или секрет уже задан). Если ключ задан переменной `CADDY_AUTH_API_TOKEN`, здесь его не поменять — действует переменная.
- **🧭 Домен подписки** — свой домен в ссылках подписки: бот заменяет в ссылке только домен, остальное не трогает.

Адрес и токен бот проверяет на панели до сохранения. Если панель не ответила, можно нажать **💾 Сохранить без проверки** — пригодится при переезде, когда адрес и токен меняются по очереди. При смене адреса на другой сервер ключ и кука сбрасываются. Сообщения с секретами бот удаляет из чата.

## Mini App и веб-кабинет

**Система → 📱 Mini App** (по умолчанию выключен):

1. Включите Mini App.
2. Задайте публичный адрес бота в «🔗 Вебхуках».
3. Скопируйте адрес мини-аппа с экрана и вставьте в @BotFather → Bot Settings → Menu Button.

**Система → 🌐 Веб-кабинет** (по умолчанию выключен) — тот же магазин на отдельном сайте, адрес по умолчанию `https://ваш-домен/cabinet/`. Вход через Telegram или по почте с паролем. Настройки:

- **✏️ Изменить путь** — адрес кабинета на сайте.
- **🛡 Одобрение новых** — пускать всех, или новые входы (только через Telegram, только по почте или все) ждут вашего одобрения.
- **✏️ Заголовок**, **✏️ Описание**, **🖼 Фавикон** — название вкладки, описание для поисковиков и значок.
- **🕵️ Анти-фингерпринт** — страница кабинета меняется от запроса к запросу, чтобы её было сложнее опознать как этого бота.
- **🚪 Разлогинить всех** — завершить все сессии кабинета и мини-аппа.

Триал в кабинете доступен только тем, кто вошёл через Telegram. Внешний вид мини-аппа и кабинета настраивается в [Интерфейс → 🎨 Дизайн мини-аппа и кабинета](/admin/interface/#дизайн-мини-аппа-и-веб-кабинета).

## ✉️ Почта кабинета

**Система → ✉️ Почта.** Без неё регистрация в кабинете идёт без подтверждения адреса и восстановления пароля. Когда почта включена:

- при регистрации нужно **подтвердить адрес**. До подтверждения закрыты покупка, пополнение, промокоды и тарифы «по списку»; вход и просмотр подписки доступны;
- можно **восстановить пароль** по ссылке из письма (ссылка действует час);
- при смене пароля на адрес приходит **уведомление**.

Аккаунты, созданные до включения почты, считаются подтверждёнными.

Способы отправки (**🔀 Способ**):

- **SMTP** — свой сервер или любой почтовый сервис (Yandex, Mail.ru, SendGrid, Mailgun). Сервер вводится как `smtp.example.com:587`; без порта подставится 587 для STARTTLS или 465 для TLS. Вход по паролю без шифрования запрещён.
- **Внешний API** — отправка через HTTPS, если хостер закрыл почтовые порты. По умолчанию — в формате [Resend](https://resend.com); адрес шлюза можно поменять.

**📨 Отправить тестовое** шлёт письмо на адрес отправителя и показывает ошибку сервера целиком — по ней видно, что не так.

Для ссылок в письмах нужен публичный адрес бота (раздел «🔗 Вебхуки»), без него письма не отправляются. На один аккаунт — не чаще письма в минуту и не больше пяти в сутки.

## 🔗 Привязка Telegram к аккаунту кабинета

На экране **«Аккаунт»** в кабинете у аккаунта по почте есть кнопка входа через Telegram. После привязки:

- входить можно и через Telegram, и по почте с паролем;
- в боте видны та же подписка, баланс и история;
- **ссылка подписки не меняется** — переподключать приложение не нужно.

Привязать можно только Telegram без своей истории в боте (подписки, платежей, баланса) — две истории покупок автоматически не объединяются, такие случаи решаются через поддержку. В закрытом боте нельзя привязать Telegram, которому бот закрыт.
