Раздел **👥 Пользователи** — список всех, кто заходил в бота.

**🔍 Найти пользователя** ищет по Telegram ID, нику, имени или почте аккаунта кабинета — достаточно части. Если в боте никого не нашлось, бот ищет учётку в панели и показывает, что с ней можно сделать.

Значок перед именем — статус подписки по данным бота:

| Значок | Статус |
|---|---|
| 🟢 | подписка активна |
| 🔵 | триал |
| 🔴 | подписка истекла |
| ⚪ | подписки не было |
| 🚫 | заблокирован |

В свежих версиях Telegram кнопка ещё и подсвечена цветом. Точное состояние из панели показано в карточке.

## Карточка пользователя

В карточке — дата регистрации, статус, последний купленный тариф и подписка со ссылкой.

| Кнопка | Что делает |
|---|---|
| 🚫 Заблокировать | Три варианта: «бот + подписка», «только подписку», «только в боте». Заблокированная подписка отключается в панели. Пользователь сразу получает сообщение о том, что ограничено, а в «📲 Мои подписки» видит, что подписка заблокирована администратором. |
| ✅ Разблокировать | Те же варианты. Показываются только применимые. |
| ✅ Разрешить P2P / 🚫 Запретить P2P | Доступ к оплате переводом. |
| ➕ В вайтлист / ➖ Из вайтлиста | Добавляет в белый список или убирает из него. |
| 📜 Нарушения | Журнал торрент-блокера по человеку. Кнопка есть, если нарушения были. |
| 🎟 Тарифы по списку | Выдаёт или забирает доступ к тарифам с доступностью «по списку». Кнопка есть, если такие тарифы заведены. |
| 🗑 Удалить из бота | Только из бота или вместе с подпиской в панели. Вход в веб-кабинет по почте удаляется в обоих случаях, адрес снова свободен для регистрации. |
| 🔗 Связать с панелью | Привязывает человека к его учётке в панели. |
| ⛓ Отвязать от панели | Снимает привязку. |

### Привязка к учётке панели

**🔗 Связать с панелью.** После привязки человек управляет подпиской из бота, триал ему не выдаётся.

- Кнопка есть у тех, кто уже заходил в бота.
- Для тех, кто не заходил, достаточно Telegram ID в учётке панели — бот привязывает её при первом входе.
- Если у человека нет Telegram (вход в кабинет по почте), бот вписывает в учётку его почту вместо Telegram ID.
- Почта, вписанная в учётку панели вручную, подхватывается кабинетом при входе, если почта подтверждена.

**⛓ Отвязать от панели.** В панели убирается только Telegram ID или почта. Учётка и подписка остаются. Учётка, созданная ботом, не отвязывается — только удаляется.

## Торрент-блокер

Если на нодах включён плагин **torrent-blocker** (панель и нода 2.7.0 и новее), панель присылает боту отчёт о каждой блокировке IP за торренты.

Настройки — **Пользователи → 🚫 Торренты**:

| Настройка | Что делает |
|---|---|
| 🚫 Торрент → админу | Отчёт администратору: кто нарушил, какое это нарушение за 30 дней, нода, IP, срок блокировки, куда шло соединение. По умолчанию включено. |
| 🚫 Торрент → юзеру | Предупреждение нарушителю, не чаще раза в 10 минут: торренты запрещены, IP заблокирован на указанное время, кнопка поддержки. По умолчанию включено. |
| ✏️ Текст разблокировки | Текст сообщения «блокировка снята», которое приходит, когда блокировка истекает. С форматированием и кнопкой «📨 Тест мне». |
| ⛔️ Автоблокировка | После N нарушений за 30 дней бот отключает подписку и сообщает об этом администратору и пользователю. По умолчанию выключена (`0`). Доступ возвращается разблокировкой в карточке. |
| 📜 Журнал торрентов | Все отчёты за 180 дней. |

Кнопки в отчёте администратору: карточка пользователя, блокировка пользователя, **🔓 Снять блокировку IP** досрочно на всех нодах, **🙈 В исключения блокера** — больше не блокировать этого пользователя.

Что нужно для работы:

1. Плагин torrent-blocker включён на нодах в панели.
2. В панели включён вебхук на `https://ВАШ_ДОМЕН/webhook/remnawave` — [Вебхуки и свой домен](/payments/webhooks/).
3. Задан секрет вебхука: **Система → 🔗 Вебхуки → 🔑 Секрет панели**, и тот же секрет в панели. Без секрета отчёты отбрасываются: иначе поддельный запрос мог бы рассылать ложные предупреждения и отключать подписки.
4. Для «Снять блокировку IP» и «В исключения блокера» токену панели нужны права `node-plugins`: list, update, executor — [Права токена панели](/reference/panel-scopes/).

Блокер ловит только часть торрент-трафика. Отчёты — это пойманные случаи, а не полная статистика.

## Доступ в бота: публично / приглашения / вайтлист

**Пользователи → 🚪 Доступ.** Режимов три, действует один.

| Режим | Кто входит |
|---|---|
| 🌍 Публично | Кто угодно. Режим по умолчанию. |
| ✉️ По приглашениям | Только перешедшие по ссылке-приглашению. |
| 🛡 Белый список | Только добавленные администратором — по Telegram ID или кнопкой в карточке. |

Режим действует и в мини-аппе, и в веб-кабинете: кого не пускает бот, того не пускает и веб.

### Приглашения

**➕ Новое приглашение** спрашивает срок действия в днях и число регистраций (`0` — без ограничения). Бот выдаёт ссылку `t.me/ВАШ_БОТ?start=inv_КОД`.

- Перешедший по ссылке получает постоянный доступ, как в белом списке. Смена режима его не закрывает.
- Об активации приходит уведомление.
- Приглашение можно отозвать или удалить.
- **👥 Кто пришёл** в карточке приглашения — список вошедших по ссылке с датой. Кнопка открывает карточку человека.
- В открытом боте ссылка доступ не выдаёт, а только записывает новичков — без лимита, срока и уведомлений.
- В режиме белого списка ссылки не действуют.

### Закрытие бота

При переходе с «публично» на другой режим бот спрашивает, что делать с уже зарегистрированными: **сохранить доступ** или **закрыть всем**.

### Белый список

**📋 Список вайтлиста** показывает всех, у кого есть доступ, и отдельно — добавленные Telegram ID тех, кто ещё не заходил.

Кнопка **🔒 Снять доступ у всех** работает с подтверждением. Администратор остаётся в боте в любом случае.

### Аккаунты кабинета по почте

В закрытом боте аккаунты кабинета по почте всегда проходят одобрение — независимо от кнопки «🛡 Почта» в настройках кабинета. Уже одобренные работают как раньше, новые ждут решения администратора.

Оплата переводом открывается всем без ручного одобрения отдельным тумблером — [P2P](/admin/sales/#p2p).
