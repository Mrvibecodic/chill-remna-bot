[ЮMoney](https://yoomoney.ru) здесь — это **перевод на ваш кошелёк**, а не магазин ЮKassa. Подходит, когда юрлица или самозанятости для ЮKassa нет: нужен только кошелёк. Покупатель платит картой или со своего кошелька ЮMoney, деньги приходят на ваш кошелёк, бот выдаёт подписку.

## Как это устроено

1. Покупатель выбирает тариф → «💜 ЮMoney» → бот открывает свою страницу, которая передаёт в ЮMoney сумму и метку счёта.
2. После перевода ЮMoney присылает боту уведомление с подписью. Бот проверяет подпись, затем **перепроверяет операцию через API кошелька** по метке и только после этого выдаёт подписку или пополняет баланс.
3. Если уведомление потерялось, оплату довыдаст кнопка «🔄 Проверить оплату» или фоновая сверка (она тоже ходит в API кошелька).

Поэтому способу нужны **три вещи**: номер кошелька, секрет уведомлений и токен API. Без любой из них способ не включится.

## Настройка в ЮMoney

1. **HTTP-уведомления.** В кошельке откройте [настройки HTTP-уведомлений](https://yoomoney.ru/transfer/myservices/http-notification), впишите адрес `https://ВАШ_ДОМЕН/webhook/yoomoney` (готовый адрес показан на экране ЮMoney в боте), включите уведомления и скопируйте **секрет**. Кнопка «Протестировать» там же — бот запишет тестовое уведомление в журнал платежей.
2. **Приложение для API.** Зарегистрируйте приложение на [yoomoney.ru/myservices/new](https://yoomoney.ru/myservices/new): любое название, в поле **Redirect URI** — адрес `https://ВАШ_ДОМЕН/webhook/yoomoney/oauth` (он тоже показан на экране в боте). Галочку «проверка подлинности» можно не ставить; если поставили — понадобится ещё и `client_secret`. Скопируйте **client_id**.

Про домен и прокси — [Вебхуки и reverse-proxy](/payments/webhooks/). Страницы ЮMoney живут под `/webhook/`, поэтому достаточно того же проброса, что и для вебхуков.

## Настройка в боте

**Продажи → 💜 ЮMoney (кошелёк):**

- **👛 Кошелёк** — номер кошелька-получателя (только цифры);
- **🔑 Секрет уведомлений** — секрет из настроек HTTP-уведомлений;
- **🆔 client_id** и при необходимости **🔐 client_secret** — из зарегистрированного приложения;
- **🔗 Авторизовать** — бот даст одноразовую ссылку (живёт 15 минут). Откройте её, разрешите доступ — ЮMoney вернёт код боту, и бот сам получит и сохранит токен. Бот сверяет, что токен выдан именно кошельку-получателю: чужой кошелёк не сохранится;
- **✍️ Ввести токен** — если токен уже есть (права `account-info` и `operation-history`);
- **🔎 Проверить токен** — живая проверка: номер кошелька по API и совпадение с получателем;
- **🔁 Карта / кошелёк** — чем платит покупатель. По умолчанию карта: кошелёк ЮMoney есть не у всех;
- **🔗 Return URL** — куда вернуть покупателя после оплаты;
- **тумблер** — показывать ли способ покупателям. Включится только при заполненных кошельке, секрете и токене, и только если кошелёк токена совпадает с получателем (бот проверяет по API при включении, при смене кошелька и при ручном вводе токена). Если после смены кошелька или токена они разошлись, бот сам выключит способ.

Токен ЮMoney живёт **3 года**. Повторная авторизация тем же приложением отзывает прежний токен — просто нажмите «Авторизовать» ещё раз.

## Деньги

- Цены — базовые цены тарифов в рублях; тариф в другой валюте и нерублёвая сетка через ЮMoney не продаются.
- Покупатель платит ровно цену тарифа. **Комиссию ЮMoney удерживает с получателя:** 3 % при оплате картой, около 1 % с кошелька. По уведомлению бот сверяет с ценой то, что заплатил покупатель; когда оплата подтверждается через API (кнопка «Проверить оплату», сверка), видна только зачисленная сумма — тогда допускается комиссия до 3 %, и это помечается в журнале строкой `api_amount`.
- Недоплата (покупатель изменил сумму на странице ЮMoney) — подписка не выдаётся, счёт закрывается, покупатель видит сообщение, вам приходит уведомление, запись остаётся в журнале платежей.
- Если покупатель оплатил одну и ту же ссылку дважды, второй раз ничего не выдаётся — бот сообщит вам, как только увидит лишнюю операцию (по уведомлению, кнопке «Проверить» или сверке), деньги верните вручную: API возвратов у кошелька нет.
- В записи платежа всегда цена счёта; фактически уплаченное и зачисленное — в журнале.
- Пополнение баланса через ЮMoney работает так же, как покупка.
- Чеки «Мой налог» для ЮMoney не формируются — только для ЮKassa.

## Журнал

В [логе заказа](/admin/sales/#история-платежей-и-аналитика) по метке счёта (`ym:…`) видна вся цепочка: `invoice_created` → `webhook` → `finalize` → `done`, а также `underpaid`, `overpaid`, `duplicate_payment`, `api_amount` и `verify_pending` (уведомление пришло раньше, чем операция появилась в истории, — ЮMoney повторит доставку через 10 минут).
