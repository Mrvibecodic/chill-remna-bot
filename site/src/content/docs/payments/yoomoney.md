[ЮMoney](https://yoomoney.ru) в боте — это **перевод на кошелёк**, а не магазин ЮKassa. Юрлицо или самозанятость не нужны, нужен только кошелёк. Покупатель платит картой или со своего кошелька ЮMoney, деньги приходят на кошелёк владельца бота, бот выдаёт подписку.

## Как это устроено

1. Покупатель выбирает тариф → «💜 ЮMoney». Бот открывает свою страницу, которая передаёт в ЮMoney сумму и метку счёта.
2. После перевода ЮMoney присылает боту уведомление с подписью. Бот проверяет подпись, затем **перепроверяет операцию через API кошелька** по метке. После этого выдаёт подписку или пополняет баланс.
3. Если уведомление потерялось, оплату выдаёт кнопка «🔄 Проверить оплату» или фоновая сверка. Она тоже обращается к API кошелька.

Способу нужны **три вещи**: номер кошелька, секрет уведомлений и токен API. Без любой из них способ не включается.

## Настройка в ЮMoney

1. **HTTP-уведомления.** В [настройках HTTP-уведомлений](https://yoomoney.ru/transfer/myservices/http-notification) кошелька нужно вписать адрес `https://ВАШ_ДОМЕН/webhook/yoomoney`, включить уведомления и скопировать **секрет**. Готовый адрес показан на экране ЮMoney в боте. Кнопка «Протестировать» там же отправляет тестовое уведомление — бот записывает его в журнал платежей.
2. **Приложение для API.** Зарегистрировать приложение на [yoomoney.ru/myservices/new](https://yoomoney.ru/myservices/new): любое название, в поле **Redirect URI** — `https://ВАШ_ДОМЕН/webhook/yoomoney/oauth` (адрес тоже показан в боте). Галочка «проверка подлинности» необязательна; с ней нужен ещё и `client_secret`. Скопировать **client_id**.

Домен и прокси — [Вебхуки и свой домен](/payments/webhooks/). Страницы ЮMoney находятся под `/webhook/`, отдельная настройка прокси для них не нужна.

## Настройка в боте

**Продажи → 💜 ЮMoney (кошелёк).**

| Кнопка | Что задаёт |
|---|---|
| 👛 Кошелёк | Номер кошелька-получателя, только цифры. |
| 🔑 Секрет уведомлений | Секрет из настроек HTTP-уведомлений. |
| 🆔 client_id · 🔐 client_secret | Данные зарегистрированного приложения. `client_secret` — если включена «проверка подлинности». |
| 🔗 Авторизовать | Бот выдаёт одноразовую ссылку, она действует 15 минут. После разрешения доступа ЮMoney возвращает код боту, бот получает и сохраняет токен. Токен чужого кошелька не сохраняется: бот сверяет его с кошельком-получателем. |
| ✍️ Ввести токен | Ввод готового токена с правами `account-info` и `operation-history`. |
| 🔎 Проверить токен | Запрос номера кошелька по API и сверка с получателем. |
| 🔁 Карта / кошелёк | Чем платит покупатель. По умолчанию карта. |
| 🔗 Return URL | Куда возвращается покупатель после оплаты. |
| Тумблер | Показывать ли способ покупателям. |

Тумблер включается, когда заполнены кошелёк, секрет и токен и кошелёк токена совпадает с получателем. Бот проверяет это по API при включении, при смене кошелька и при ручном вводе токена. Если после смены кошелька или токена они разошлись, бот выключает способ сам.

Токен ЮMoney действует **3 года**. Повторная авторизация тем же приложением отзывает прежний токен; новый выдаётся кнопкой «Авторизовать».

## Деньги

| Вопрос | Как работает |
|---|---|
| Цены | Базовые цены тарифов в рублях. Тариф в другой валюте через ЮMoney не продаётся. |
| Комиссия | Покупатель платит ровно цену тарифа. Комиссию ЮMoney удерживает с получателя: 3 % при оплате картой, около 1 % с кошелька. |
| Сверка суммы | По уведомлению бот сверяет с ценой то, что заплатил покупатель. При подтверждении через API (кнопка «Проверить оплату», сверка) видна только зачисленная сумма — допускается комиссия до 3 %, в журнале это строка `api_amount`. |
| Недоплата | Покупатель изменил сумму на странице ЮMoney. Подписка не выдаётся, счёт закрывается. Покупатель видит сообщение, администратору приходит уведомление, запись остаётся в журнале платежей. |
| Двойная оплата одной ссылки | Второй раз ничего не выдаётся. Бот сообщает администратору, когда видит лишнюю операцию. Возврат — вручную: API возвратов у кошелька нет. |
| Запись платежа | В записи — цена счёта. Фактически уплаченное и зачисленное — в журнале. |
| Пополнение баланса | Работает так же, как покупка. |
| Чеки «Мой налог» | Для ЮMoney не формируются — только для ЮKassa. |

## Журнал

В [логе заказа](/admin/sales/#istoriya-platezhey-i-analitika) по метке счёта (`ym:…`) видна вся цепочка: `invoice_created` → `webhook` → `finalize` → `done`.

| Запись | Что значит |
|---|---|
| `underpaid` | недоплата |
| `overpaid` | переплата; излишек на баланс не зачисляется |
| `duplicate_payment` | повторная оплата того же счёта |
| `api_amount` | сумма подтверждена через API, с учётом комиссии |
| `verify_pending` | уведомление пришло раньше, чем операция появилась в истории. ЮMoney повторяет доставку через 10 минут. |
