## Установка за 4 шага

1. Скачать `docker-compose.yml` в пустую папку на сервере.
2. Вписать в него токен бота от [@BotFather](https://t.me/BotFather) и свой Telegram ID.
3. Запустить `docker compose pull && docker compose up -d`.
4. Открыть бота в Telegram и пройти мастер настройки.

С командами — [Установка за 4 шага](/start/install/).
