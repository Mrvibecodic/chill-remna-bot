## Установка за 4 шага

<Steps>

1. Скачайте `docker-compose.yml` в пустую папку на сервере.

2. Впишите в него два значения: токен бота от [@BotFather](https://t.me/BotFather) и свой Telegram ID.

3. Запустите `docker compose pull && docker compose up -d`.

4. Откройте бота в Telegram и пройдите мастер настройки.

</Steps>

Подробно, с командами — [Установка за 4 шага](/start/install/).
