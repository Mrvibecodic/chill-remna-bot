description: Условия использования бота и сторонние компоненты.

Бот распространяется по лицензии **MIT** (файл [LICENSE](https://github.com/Mrvibecodic/chill-remna-bot/blob/main/LICENSE)). Его можно бесплатно использовать, изменять, разворачивать у себя и продавать через него доступ. Условие одно: в копиях кода нужно сохранять текст лицензии и уведомление об авторских правах. Код предоставляется «как есть», без каких-либо гарантий.

Сторонние компоненты внутри бота (модули Go, библиотека QR-кодов, иконки Mini App) перечислены с лицензиями в [THIRD-PARTY-NOTICES.md](https://github.com/Mrvibecodic/chill-remna-bot/blob/main/THIRD-PARTY-NOTICES.md). Все они под MIT, ISC, BSD или Apache-2.0 (код SQLite — public domain), так что копилефт-требований на код бота не переносят. Программы базового образа Alpine (busybox, docker-cli и другие) — отдельные, со своими лицензиями, и на бота тоже не влияют; подробности там же.

С панелью **Remnawave** бот работает только через её публичное HTTP API, кода панели в нём нет.
