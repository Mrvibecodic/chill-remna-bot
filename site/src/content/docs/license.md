Код бота распространяется по лицензии **MIT** — см. файл [LICENSE](https://github.com/Mrvibecodic/chill-remna-bot/blob/main/LICENSE). Можно
свободно использовать, изменять, разворачивать у себя и продавать доступ; единственное
условие — сохранять текст лицензии и уведомление об авторских правах в копиях кода.

Сторонние компоненты, попадающие в бинарник и в статику бота (модули Go, библиотека
QR-кодов, иконки Mini App), перечислены с лицензиями и уведомлениями в
[THIRD-PARTY-NOTICES.md](https://github.com/Mrvibecodic/chill-remna-bot/blob/main/THIRD-PARTY-NOTICES.md) — все под MIT / ISC / BSD / Apache-2.0 (код SQLite — public domain),
то есть на код бота никаких копилефт-требований не переносится. Пакеты внутри базового
образа Alpine (busybox, docker-cli и прочие) — отдельные программы со своими лицензиями,
на бота они тоже не влияют; подробности там же.

Бот работает с панелью **Remnawave** только через её публичное HTTP API и кода панели
не содержит.
